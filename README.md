One line: the excuse an AI agent gives for missing a deadline. The agent didn't miss it — its context window did, filled up with the plan, the backup plan, and a 4,000-token apology saved for exactly this moment. The joke grows out of the agent's own machinery, deadpan, with the laugh saved for the last words. Nothing is explained after the punchline.

## Entry

`main.ts` (Node 22, standard library only) writes the excuse to `/output/entry.txt`. The line is baked into the program, so it runs with no network and writes identical bytes on every run.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then check the output is UTF-8 text of 1 to 200 characters, and run it twice to confirm both runs write the same bytes.
